# Conditionals: a finished version

One way to build the song in `conditionals/start/song.js`, all six steps done. Comments mark which step each part comes from. `demos.js` is the same as in `start/`: the four demos from the lecture.

Yours can look different and still be right: other notes, other sections, other names. What matters is that you can point at each `if` and say what question it asks, and what plays when the answer is `true`.

Run it the same way as `conditionals/start`: open `index.html` with Live Preview, open the console, and press Play.

Don't change these files. Read them, copy from them, run them, but make your own changes in `conditionals/start`.
